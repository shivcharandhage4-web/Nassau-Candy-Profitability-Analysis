# Nassau Candy Distributor — Profitability Analysis

## Files
- `Nassau_Candy_Research_Paper.docx` — research paper
- `Executive_Summary.docx` — executive summary
- `app.py` — Streamlit dashboard
- `cleaned_dataset.csv` — validated/augmented data
- `product_profitability.csv` — product-level metrics
- `division_performance.csv` — division metrics
- `charts/` — report charts

## Run dashboard
1. Install Python 3.10+
2. Open a terminal in this folder
3. Run `pip install -r requirements.txt`
4. Run `streamlit run app.py`
